# 📊 Calculadora de IMC em C

Um programa simples em linguagem **C** que calcula o Índice de Massa Corporal (IMC) e informa a classificação de acordo com os padrões de saúde.

## 🚀 Funcionalidades

- **Cálculo preciso do IMC:** Recebe o peso (em kg) e a altura (em metros).
- **Classificação do IMC:** Indica se a pessoa está abaixo do peso, no peso ideal, com sobrepeso ou em algum grau de obesidade.
- **Estrutura de Repetição:** Permite realizar múltiplos cálculos sem precisar reiniciar o programa a cada consulta.

## 📈 Tabela de Classificação

| IMC | Classificação |
|---|---|
| Menor que 18.5 | Abaixo do peso ideal |
| 18.5 – 24.9 | Peso ideal |
| 25.0 – 29.9 | Sobrepeso |
| 30.0 – 34.9 | Obesidade grau I |
| 35.0 – 39.9 | Obesidade grau II |
| 40.0 ou mais | Obesidade grau III |
